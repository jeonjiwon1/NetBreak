# 사용자 Unity 수동 검증 순서

이 목록은 사용자가 직접 실행한다. 이번 작업에서는 Unity/Import/컴파일/Console/Play를 실행하지 않았다.

1. 기존 프로젝트를 열고 Import와 컴파일이 끝난 뒤 Console의 신규 오류를 확인한다.
2. 기존 Area 1 씬으로 진입해 1920×1080 및 실제 사용 해상도에서 일곱 UI 영역의 위치/크기와 4개 아이템·5개 Hotbar 슬롯이 기존과 같은지 확인한다.
3. 좌측 간판의 NETBREAK·야자수·갈매기와 정보 7행을 확인한다. 경험치 숫자/게이지/구분선이 겹치지 않는지 본다. 0 EXP, EXP 획득, 레벨업 후 게이지가 숫자와 함께 변하는지 확인한다.
4. 좌측 및 아이템 HUD를 기존 방식으로 드래그한다. 화면 가장자리에서도 간판/장식/텍스트가 잘리지 않는지 확인한다. 장식 때문에 클릭이 차단되지 않는지 확인한다.
5. 시간 UI의 시계·시간, 조업 준비 제목·물고기 음영·로프·하단 연속 파도를 확인한다. 파도 타일 이음새/버튼 겹침이 없어야 한다. 조업 시작 버튼이 기존처럼 동작하고 패널 전체가 닫히는지 확인한다.
6. 아이템 번호 1~4, +, 빈 슬롯 문구를 확인한다. 아이템 보유 상태를 확인할 수 있는 기존 경로에서 아이콘/등급/툴팁도 확인한다. 정상 Area 1에 아이템을 새로 지급할 필요는 없다.
7. Hotbar의 LMB/Q/W/E/R, 선택 강조, 빈 슬롯·잠김·획득 상태와 동적 도구 아이콘을 확인한다. 연결 기둥과 큰 로프가 글자를 가리지 않아야 한다. 키 바인딩·도구 사용·툴팁·UI 입력 차단은 기존과 같아야 한다.
8. x1/x2/x3의 글자·선택 상태 및 배속 동작, 성장 관리 버튼과 Tab의 열기/닫기 동작을 확인한다.
9. 작은 Game View와 큰 Game View에서 한글 위/아래 잘림, 긴 수치·상태 문자열의 생략, 프레임 바깥 글자, 9-slice 모서리 단절/찢어짐을 확인한다. 특히 19px EXP 행·20px 숫자 배지·18px 아이템 문구 높이를 확인한다.
10. Console에 신규 오류가 없는지 확인하고 목표 레퍼런스와 전체 분위기를 비교한다. 이상이 있으면 해상도, 상태, 해당 UI를 기록한다. 이 확인 전까지 최종 아트 승인 상태는 Pending이다.
