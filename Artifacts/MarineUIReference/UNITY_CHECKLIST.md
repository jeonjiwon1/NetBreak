# 사용자 Unity 확인

이번 작업에서 Unity 실행/컴파일/Play/수동 검증은 하지 않았다.

- [ ] 기존 프로젝트의 Import/컴파일 완료 후 Console 오류 확인.
- [ ] 주요 UI 위치·크기·아이템 4칸·Hotbar 5칸이 유지되는지 확인.
- [ ] 좌측 HUD/간판: 목재 결·둥근 픽셀 경계·감긴 로프·정보 행과 EXP 게이지 확인.
- [ ] 중앙 시간/준비: 시간 가독성, 청록 배경 무늬, 물고기 음영, 파도 곡선과 버튼 글자 겹침 확인.
- [ ] 우측 아이템: 1~4, 빈 슬롯·보유 상태·툴팁과 테두리 겹침 확인.
- [ ] 좌하단 LMB 선택 슬롯 및 중앙 하단 Hotbar: Cyan 선택 경계, 슬롯 상하 로프 연결부, 키·아이콘·상태 문구 확인.
- [ ] 우하단 성장/배속: Navy 내부와 밝은 글자, x1/x2/x3 선택 강조, 버튼·Tab 동작 확인.
- [ ] HUD 드래그와 화면 끝 Clamp, UI 입력 차단이 그대로인지 확인.
- [ ] 실제 사용하는 해상도에서 타일 반복 무늬가 과하지 않은지, 고정 모서리·잘린 마지막 타일 이음새가 자연스러운지 확인.
- [ ] 첨부 레퍼런스와 재질/장식/픽셀 밀도를 나란히 비교. 기존 크기·폰트는 유지했으며 디자인 동일성은 아직 승인되지 않은 상태.
