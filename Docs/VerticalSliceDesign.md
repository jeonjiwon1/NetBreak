# NETBREAK
## Vertical Slice Design Document v0.1

**목적:** 빌드 다양성과 완성형 플레이 경험 검증  
**엔진:** Unity 6 / C#  
**개발 인원:** 1명  
**선행 조건:** Core Prototype v1.2 완료  
**대상 콘텐츠:** 완성도 있는 연안 해역 1개

---

# 1. Vertical Slice의 목적

Core Prototype은 다음 질문을 1차적으로 통과했다.

> **어군을 유도하고 봉쇄한 뒤 한 번에 포획하는 기본 루프가 재미있는가?**

Vertical Slice는 다음 질문을 검증한다.

> **같은 해역을 여러 번 플레이해도 서로 다른 빌드와 전직 때문에 실제 플레이 방식이 달라지는가?**

두 번째 질문:

> **실제 게임에 가까운 UI/VFX/SFX와 한 개의 완성형 해역을 제공했을 때 NETBREAK의 정체성이 충분히 전달되는가?**

---

# 3. 개발 원칙

Vertical Slice는 콘텐츠 양을 늘리는 단계가 아니다.

우선순위:

1. 빌드 차이
2. 게임 가독성
3. 한 해역의 완성도

다음은 최소화한다.

- 해역 수
- 스토리
- 영구 성장
- 도감
- 2차 전직
- Hard Mode
- 수집 콘텐츠

# 5. 목표 플레이타임

Vertical Slice 1 Run:

**약 12~20분**

정확한 시간은 구현 후 조정한다.

Vertical Slice에서는 빌드 재시도와 비교가 중요하므로 지나치게 긴 Run은 피한다.

---

# 6. 완성형 연안 해역

목표:

- NETBREAK의 시각적 정체성 제공
- 조업 준비의 의미 강화
- 어군 이동을 읽을 수 있는 지형 제공
- 서로 다른 빌드가 모두 활용될 공간 제공

기본 구조:

- 한 화면 또는 제한된 카메라 이동
- 넓은 수면
- 암초/얕은 지형 2~4개
- 설치 불가 구역
- 2개 이상의 주요 어군 진입 구역
- 자연스럽게 생기는 포획 포인트

고정 Lane은 사용하지 않는다.

---

# 7. 조업 준비 — Vertical Slice 버전

시작 전 표시:

- 주요 어종
- 예상 어군 규모
- 어군 진입 가능 구역
- 현재 Gold
- 보유 설치형 어구
- 조업 시작 버튼

준비 단계에서 가능:

- 그물 설치
- 낚싯대 설치
- 설치물 회수/재배치

준비 단계에서 불가능:

- 뜰채
- 미끼
- 투망

목표:

> **플레이어가 첫 어군이 오기 전에 자신의 초기 조업 계획을 세운다.**

---

# 8. 기본 도구

## 8.1 뜰채
모든 빌드가 가진 기본 직접 포획 수단.

기본 역할:

- 소수 개체 처리
- 약화 개체 마무리
- 탈출 직전 물고기 처리

뜰채잡이 전직에서는 주력 포획 수단으로 변화한다.

## 8.2 미끼
모든 빌드가 활용 가능한 기본 LURE 도구.

역할:

- 어군 압축
- 이동 방향 변경
- 포획 지점 형성

## 8.3 그물
설치형 TRAP.

역할:

- 감속
- Resistance 약화
- 이동 제한
- 포획 구역 형성

## 8.4 투망
수동 범위 포획 액티브.

역할:

- 밀집 어군 대량 포획
- 타이밍 기반 보상

## 8.5 낚싯대 — 신규

대형어·고가치 개체를 자동 또는 반자동으로 지속 포획하는 설치형 어구.

Vertical Slice 기본안:

- 설치 위치 지정
- 일정 사거리 내 목표 1마리 선택
- Resistance 지속 감소
- 대형어 우선 타겟 성향
- 다수 소형어에는 낮은 효율

목적:

> **대량 포획이 아닌 단일 고가치 목표 빌드가 성립하는지 검증한다.**

---

# 9. 1차 전직

Vertical Slice에서는 **1차 전직만 구현**한다.

2차 전직은 구현하지 않는다.

전직 시점 초기안:

**3번째 어군 종료 또는 Level 4 전후**

정확한 시점은 플레이테스트로 조정한다.

모든 Run은 초보 어부로 시작한다.

---

# 10. 1차 전직 후보

## 10.1 투망꾼

핵심:

> **어군을 최대한 압축해 한 번의 투망으로 크게 터뜨린다.**

전직 효과 예:

- 투망 범위 증가
- 대량 포획 시 쿨다운 일부 반환
- 투망 관련 증강 등장 가중치 증가

플레이 방식:

**미끼 → 압축 → 투망**

---

## 10.2 그물잡이

핵심:

> **설치와 공간 제어로 어군을 통제한다.**

전직 효과 예:

- 그물 최대 개수 증가
- 그물 포획/감속 효과 증가
- 그물 길이 비용 효율 개선
- 그물 관련 증강 등장 가중치 증가

플레이 방식:

**준비 배치 → 미끼 유도 → 봉쇄 구역 운영**

---

## 10.3 낚시꾼

핵심:

> **소수의 고가치·대형어를 효율적으로 처리한다.**

전직 효과 예:

- 낚싯대 포획력 증가
- 대형어 우선 타겟
- 추가 Hook
- 낚싯대 관련 증강 등장 가중치 증가

플레이 방식:

**대형어 선별 → 낚싯대 지속 압박 → 다른 도구로 소형 어군 처리**

---

## 10.4 뜰채잡이

핵심:

> **플레이어 직접 조작으로 어군을 빠르게 정리한다.**

전직 효과 예:

- 최대 동시 타격 수 증가
- 쿨다운 감소
- 연쇄 포획
- 뜰채 관련 증강 등장 가중치 증가

플레이 방식:

**정밀 클릭 → 연쇄/다중 포획 → 높은 직접 개입**

---

# 11. 전직 선택 방식

전직은 랜덤 3택1 증강과 구분한다.

Vertical Slice에서는 **해금된 4개 전직을 직접 선택**할 수 있게 한다.

현재 빌드 상태를 기준으로 추천 표시를 제공할 수 있다.

예:

**추천: 투망꾼**  
`투망 관련 증강 3개 보유`

추천은 강제가 아니다.

전직 선택 후 변경 불가.

Run 종료 시 초보 어부로 초기화한다.

---

# 12. 증강 시스템 확장

Prototype의 단순 수치형 증강만으로는 빌드 차이가 충분하지 않다.

Vertical Slice에서는 **Rule-changing 증강**을 핵심으로 추가한다.

목표 총량:

**약 16~24개**

이 중 최소 절반은 단순 수치 증가가 아닌 플레이 규칙 변경형으로 한다.

---

# 13. Rule-changing 증강 예시

## 투망

### 만선
한 번에 일정 수 이상 포획하면 투망 쿨다운 일부 반환.

### 이중 투망
투망 사용 후 짧은 시간 뒤 동일 위치에 두 번째 약한 투망 발동.

### 밀집 포획
범위 안 물고기 수가 많을수록 포획력 증가.

## 그물

### 미세 그물
소형어가 그물에 닿을 때 추가 Resistance 감소.

### 봉쇄선
두 그물이 가까이 설치되면 사이 영역의 물고기 이동속도 감소.

### 경제망
긴 그물 설치 비용 감소.

## 낚싯대

### 대어 전문
대형어 포획력 증가, 소형어 효율 감소.

### 추가 Hook
동시에 두 개체 포획.

### 끌어오기
걸린 물고기를 설치 지점 쪽으로 조금 이동.

## 뜰채

### 넓은 뜰채
범위 증가, 포획력 감소.

### 연쇄 포획
물고기 포획 시 가까운 개체에게 일부 포획 피해.

### 숙련된 손
연속 포획 성공 시 짧은 시간 사용 속도 증가.

## 미끼 / 범용

### 농축 미끼
범위는 감소하지만 중심부 압축력 증가.

### 대어용 미끼
대형어의 Bait Attraction 증가.

### 잔향
미끼 종료 후 짧은 시간 약한 유인 효과 유지.

---

# 14. 증강 Pool과 전직

전직 이후 관련 증강 출현 확률을 높인다.

예시 — 투망꾼:

- 투망 계열 40~50%
- 미끼/보조 계열 20~30%
- 범용 20%
- 기타 10%

정확한 확률은 테스트 후 조정한다.

목적은 전직 후 **주력 1개 + 보조 1~2개** 형태로 수렴하게 만드는 것이다.

---

# 15. 어종 구성

기존:

- 정어리
- 고등어
- 참치

추가 목표:

- 복어
- 오징어

총 **5종**을 목표로 한다.

---

# 16. 신규 어종 — 복어

목표:

> **그물 빌드에 새로운 판단을 만든다.**

간단한 구현안:

- 그물에 일정 시간 닿으면 팽창
- 팽창 중 해당 그물의 포획 효과 감소
- 뜰채/투망으로 빠르게 제거하면 운영이 편해짐

복잡한 내구도 시스템이 없다면 그물 효과 감소만 우선 구현한다.

---

# 17. 신규 어종 — 오징어

목표:

> **설치물 의존 빌드에 순간 대응을 요구한다.**

간단한 구현안:

- 일정 주기로 먹물 사용
- 가까운 설치형 어구 하나를 잠시 비활성화
- 뜰채/투망으로 우선 제거하면 운영이 편해짐

가장 단순한 형태로 구현한다.

---

# 18. Resistance 시각화

Vertical Slice에서는 대형어와 특수어의 Resistance를 읽을 수 있어야 한다.

권장:

## 소형어
- 기본 숨김
- 피해받았을 때 잠깐 표시

## 대형어 / 특수어
- 개체 위 작은 Resistance Bar

## 보스
- 화면 상단 전용 Resistance UI

목적:

> **투망에 맞았는데 포획되지 않은 이유를 즉시 이해하게 한다.**

---

# 19. 연안 최종 이벤트

Vertical Slice v0.1에서는 복잡한 보스보다 **최종 특수 어군**을 우선한다.

예:

- 대규모 정어리
- 고등어
- 참치
- 복어/오징어 일부

가 동시에 등장하는 혼합 어군.

장점:

- 보스 AI 개발 부담이 적음
- 현재 핵심 어군 시스템을 직접 검증
- 여러 빌드가 같은 문제를 다른 방식으로 풀 수 있음

보스는 이후 단계에서 추가한다.

---

# 20. 해역 진행 구성 예시

총 8~10회 어군 유입을 목표로 한다.

예:

1. 정어리
2. 고등어
3. 정어리 대어군
4. 참치
5. **1차 전직**
6. 고등어 + 복어
7. 정어리 + 오징어
8. 참치 + 특수어
9. 대규모 혼합 어군
10. 최종 특수 어군

그 후:

**마감 조업 → 결과**

실제 구성은 테스트로 조정한다.

---

# 21. Gold와 설치물

Vertical Slice에서는 Gold 경쟁을 Prototype보다 한 단계 확장한다.

Gold 사용처:

- 그물 설치
- 낚싯대 설치
- 필요 시 설치물 회수/재배치 비용
- 제한적인 강화

복잡한 상점은 아직 필수가 아니다.

목표:

> **같은 Gold로 어떤 조업 방식에 투자할지 고민하게 만든다.**

---

# 22. 실제 UI

Prototype의 OnGUI는 Vertical Slice에서 제거한다.

Unity Canvas + TextMeshPro 기반으로 교체한다.

필수 HUD:

- Gold
- 어획률
- EXP / Level
- 어군 진행도
- 투망 쿨다운
- 미끼 상태
- 현재 그물/낚싯대 수
- 마감 조업
- 현재 전직
- 조업 준비/시작
- 증강 선택
- 전직 선택
- 결과 화면

플레이어 노출 텍스트는 한국어를 기본으로 한다.

# 23. Game Feel

## 포획
- 짧은 Scale/Flash
- 물 튀김
- 포획 숫자
- Gold 획득 표시
- 간단한 SFX

## 투망
- 조준 범위
- 투척/확장 연출
- 한 번에 잡힌 숫자 강조
- 대량 포획 시 더 강한 효과

## 미끼
- 물속 확산 표현
- 유효 범위 가독성

## 그물
- 설치 Preview
- 물고기 접촉 반응
- 감속 상태 가독성

최종 아트 수준까지 만들 필요는 없다.

# 24. 아트 방향

Vertical Slice에서는 최종 상용 아트보다 **일관된 임시 완성도**가 목표다.

필요:

- 실제 물고기 형태 Sprite
- 수면 배경
- 암초/지형
- 미끼
- 그물
- 투망
- 낚싯대
- 최소 VFX

연안은 상대적으로 현실적인 분위기에서 출발하되 코믹 판타지 방향을 유지한다.

# 27. 성공 기준

1. 4개의 1차 전직이 실제 플레이 방식을 다르게 만드는가?
2. 전직 후 관련 증강이 나오면 반가운가?
3. 한 Run에서 2~3개 시스템에 자연스럽게 집중하는가?
4. 모든 도구를 조금씩 찍는 것이 최적해가 되지 않는가?
5. 낚싯대가 투망/그물과 다른 역할을 가지는가?
6. 5어종의 대응 방식이 구분되는가?
7. 조업 준비에서 설치 위치를 고민하게 되는가?
8. Gold 사용처가 서로 경쟁하는가?
9. 실제 UI와 VFX/SFX가 대량 포획의 만족감을 강화하는가?
10. 한 판 종료 후 다른 전직으로 다시 해보고 싶은가?

가장 중요한 질문:

> **이번 판과 다음 판의 플레이 방식이 실제로 달라질 것 같은가?**

# 28. 실패 판정

다음 중 하나가 발생하면 콘텐츠를 더 늘리지 않고 해당 시스템을 수정한다.

- 전직을 골라도 플레이 방식이 거의 같음
- 투망이 모든 빌드의 필수 주력으로 남음
- 특정 장비가 다른 장비를 완전히 대체
- 모든 증강을 골고루 먹는 것이 최적
- 낚싯대가 단순한 자동 DPS 장비로만 느껴짐
- 새 어종이 단순 Resistance 차이로만 느껴짐
- UI/VFX를 추가해도 대량 포획 순간이 약함

# 29. 완료 조건

다음 경험이 완성되면 Vertical Slice v0.1을 완료한다.

> **같은 연안 해역에 다시 출항했는데, 이번 Run은 전직과 증강 선택 때문에 이전 Run과 다른 방식으로 물고기를 잡게 된다.**

예:

Run A:

**초보 어부 → 투망꾼 → 미끼 압축 → 대량 투망**

Run B:

**초보 어부 → 그물잡이 → 사전 배치 → 봉쇄 조업**

Run C:

**초보 어부 → 낚시꾼 → 참치/대형어 집중 포획**

Run D:

**초보 어부 → 뜰채잡이 → 직접 연쇄 포획**

이 네 가지가 실제 플레이에서 충분히 구분되면 빌드 시스템의 기반이 검증된 것으로 판단한다.
