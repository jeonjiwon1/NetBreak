# NETBREAK

**NETBREAK** is a 2D roguelite fishing-defense/strategy game built in Unity.

## Core Concept

> **LURE → TRAP → CATCH**

Observe fish-school behavior, lure fish into favorable positions, control their movement with fishing gear, and capture large groups at once.

## Core Features

- Free-moving fish schools without fixed lanes
- Bait-based movement manipulation
- Free-form placement of nets and fishing gear
- Direct cursor-based capture
- Large-scale cast-net capture
- Roguelite augments and build specialization
- In-run job progression: Beginner Fisher → 1st Job → 2nd Job
- Every run starts from Area 1

## Current Status

**Prototype development**

The prototype focuses on validating the core gameplay loop:

1. Fish-school movement
2. Bait attraction
3. Net placement
4. Direct capture
5. Cast-net mass capture
6. Catch-rate based clear/fail

## Project Goal

The most important moment in NETBREAK is:

> Prepare the school, gather the fish, and capture a large number of them at once.

The prototype will be considered successful if this process is strategically interesting and the final mass-capture moment feels satisfying.
